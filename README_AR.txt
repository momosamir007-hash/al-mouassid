# إعادة تصميم المساعد — الحزمة الشاملة

هذه الحزمة مبنية على المستودع الأصلي، وتحتوي على الملفات التي تغيرت بصرياً فقط، مع الإبقاء على بقية المشروع كما هو.

## طريقة التطبيق
1. احتفظ بنسخة احتياطية من المشروع الأصلي.
2. فك ضغط الحزمة في مجلد مؤقت.
3. انسخ محتويات الحزمة إلى جذر المشروع مع الحفاظ على المسارات، ووافق على استبدال الملفات المتطابقة.
4. لا تحذف أي ملفات أخرى من المشروع.
5. شغّل `npm install` إذا لم تكن التبعيات مثبتة، ثم `npm run lint` و`npm run build` وفق scripts الموجودة في package.json.

## نطاق التغيير
- `src/app/globals.css`: نظام الألوان، البطاقات، الأزرار، الحقول، تجاوب الهاتف.
- `src/app/page.tsx`: الصفحة الرئيسية والبانر وصورة الطالب.
- `src/components/AppShell.tsx`: الترويسة والشريط الجانبي والتنقل السفلي للهاتف.
- `src/components/AuthForm.tsx`: واجهة الدخول والتسجيل وإضافة لوحة الكتب.
- `public/images/student-photo.png`: صورة الطالب الفوتوغرافية المولدة.
- `public/images/books-illustration.svg`: رسم الكتب وقبعة التخرج.

تؤثر التنسيقات العامة المشتركة أيضاً على صفحات حل التمارين، التصوير وOCR، التمارين الجديدة، المكتبة، السجل، الإعدادات، الحالة، والإدارة. لم يتم تعديل API أو قاعدة البيانات أو منطق المصادقة أو المزامنة أو محرك الذكاء الاصطناعي.

## ملاحظة تحقق
لم يتم تنفيذ بناء Next.js أو اختبارات المتصفح ضمن هذه الحزمة؛ يجب تشغيل اختبارات المشروع محلياً قبل النشر. كما أن معاينة التصميم لا تضمن تطابقاً حرفياً مع الصورة المرجعية على كل مقاس شاشة.
