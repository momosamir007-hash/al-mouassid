# الاختبارات ونتائجها

## 1) اختبارات الوحدة والتكامل (vitest) — `npx vitest run`
**ملاحظة مهمة:** الأرقام والنتائج في هذا الملف تاريخية وتخص النسخة السابقة من المستودع. أضيفت اختبارات انحدار في هذه الحزمة، ولم تُشغّل بعد؛ لا تعتبر هذه النتائج إثباتاً لسلامة النسخة المعدّلة حتى يُنفذ `npm test` و`npm run typecheck` و`npm run build`.

| الملف | يغطي |
|---|---|
| `tests/router.test.ts` | التحويل عند كل نوع خطأ (quota, rate_limit, auth, unavailable, network, timeout) **مع التأكد من محاولة واحدة فقط للمزود**، الإيقاف المؤقت، الحدود اليومية، تصفية المهام والمعطّلين، المحلي غير الجاهز لا يُستدعى، المحلي الجاهز يُستعمل بعد فشل السحابي، `none_configured`، توجيه الصور لنماذج الرؤية فقط، حساب التكلفة، سياسات quality/cost/speed |
| `tests/adapters-http.test.ts` | المحوّلات الأربعة الحقيقية عبر **خوادم HTTP محلية** (ترويسات المصادقة، صيغة الصور، قراءة الرد والرموز)، فحص جاهزية Ollama (غير منزَّل/جاهز/غير متصل)، تصنيف أخطاء HTTP، المهلة، انقطاع الاتصال، **عدم تسريب المفتاح في رسائل الخطأ أو الرابط**، سيناريو OpenAI ينفد رصيده ← Gemini، وسيناريو فشل السحابيين ← Ollama |
| `tests/learning.test.ts` | المحرك الحسابي الآمن، التعرف على التمرين الحسابي، التحقق واكتشاف الخطأ الشائع (دون كشف الناتج)، فحص وضوح التمرين، منع كشف الحل في كل زر عدا «الحل الكامل»، التكيف مع المستوى، حفظ السياق، حذف البيانات الشخصية، رفض التمرين غير الواضح قبل أي استدعاء، التحقق المحلي عند غياب المزودين، تشفير AES-GCM |

## 2) اختبار شامل يدوي على النسخة المبنية (`next start` + `scripts/fake-provider.mjs`)
نُفِّذ فعلياً عبر curl على قاعدة PostgreSQL حقيقية، وكانت النتائج:

| السيناريو | النتيجة |
|---|---|
| `/api/help` بلا جلسة | 401 |
| تسجيل الحسابات | كل حساب `learner` افتراضياً؛ أول مدير يحتاج `BOOTSTRAP_ADMIN_TOKEN` الصحيح، ولا يُستهلك إلا عند عدم وجود مدير |
| متعلم يطلب `/api/admin/providers` | 403 |
| لا مزود مفعّل عدا Ollama غير متصل | 503 `no_provider` برسالة واضحة تذكر أن المحلي غير جاهز، بلا إجابة مخترعة |
| إضافة مزودين وهميين (حصة منتهية + Gemini) | يُحفظ المفتاح **مشفّراً** (`v1.…`) ولا يظهر في API (فقط `••••7890`) |
| طلب مساعدة | أجاب Gemini بعد فشل الأول بـ `quota`؛ `fallbacks` تعرض ذلك |
| طلب ثانٍ | الأول **لم يُستدعَ** (إيقاف مؤقت): ضربة واحدة فقط على مزود الحصة |
| تمرين غير واضح `12 + ???` | 422 مع الأسباب |
| `check_answer` بلا إجابة | 400 |
| صورة مع مزود يدعم الرؤية | `imageUsed=true` |
| اختبار اتصال للمزودين | نجح/فشل `quota` بشكل صحيح |
| تعطيل Gemini | الموجّه انتقل إلى Ollama الوهمي الجاهز (`isLocal=true`) |
| تعطيل الكل + `check_answer` حسابي | `source: "local"` — كشف خطأ ترتيب العمليات دون كشف الناتج |
| مزامنة + حذف | تمرين محلي رُفع، المحذوف طُبِّق |
| كل الصفحات و`manifest` و`sw.js` والأيقونة | 200 |
| حذف الحساب بكلمة مرور خاطئة/صحيحة | 401 / ok |
| سجلات الخادم | لا أثر للمفتاح |

## 3) اختبارات الانحدار الجديدة التي أضيفت
- أولوية `-2^2` و`(-2)^2` و`2^-2`، واستخراج التعبير ذي الإشارة السالبة.
- عدم التقاط آخر رقم عشوائياً من شرح الطالب.
- الحفاظ على رمز القيمة المطلقة وعلامات OCR غير الواضحة.
- إخفاء أرقام الهاتف المكتوبة بالأرقام العربية.
- فشل readiness وفشل تسجيل الاستهلاك دون إسقاط إجابة ناجحة.
- رفض الرد المبتور عند نفاد حد الرموز.

## 4) لم يُختبر (بصدق)
- **المزودون السحابيون الحقيقيون**: لا مفاتيح في بيئة التطوير. المحوّلات مبنية على وثائق البروتوكولات واختُبرت بمحاكاة HTTP؛ يجب اختبارها بمفتاحك من لوحة الإدارة (زر «اختبار الاتصال» و«اختبار الموجّه»).
- **Ollama الحقيقي** (لا يوجد في بيئة التطوير) — ببروتوكوله فقط.
- **OCR والكاميرا والقص** في متصفح/هاتف حقيقي — لا اختبارات واجهة آلية (Playwright) بعد.
- **اختبار انقطاع الإنترنت** في المتصفح (Service Worker) — مكتوب لكن لم يُختبر آلياً؛ طريقة الاختبار اليدوي: `npm run build && npm start`، افتح الصفحات مرة، ثم Chrome DevTools ← Network ← Offline وأعد التحميل.
- اختبارات الأداء والحِمل، واختبارات الهواتف.
