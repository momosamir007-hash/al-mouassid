# المساعد – AL MOUASSID

منصة تعليمية ذكية متعددة مزودي الذكاء الاصطناعي. تساعد المتعلم على **فهم التمرين وحله تدريجياً** (تلميح ← خطوة ← تحقق ← حل كامل) بدل إعطائه الجواب مباشرة.

> ⚠️ **انحراف هندسي مُبرَّر عن المواصفة:** بيئة التنفيذ المتاحة لهذا المشروع هي **Next.js (App Router) + TypeScript + PostgreSQL عبر Drizzle ORM**
> وليست React/Vite + Express + Prisma. لذلك بُني المشروع كتطبيق Next.js واحد، مع الحفاظ على **الفصل المعماري المطلوب** بين الواجهة والخادم ووحدات الذكاء الاصطناعي
> (انظر `docs/architecture/overview.md`). المنطق الأساسي (الموجّه، المزودون، محرك التعلم) وحدات TypeScript مستقلة لا تعتمد على Next.js ويمكن نقلها إلى Express بسهولة.
> كما استُعمل TypeScript بدل JavaScript لأن القالب المتاح مبني عليه. SQLite غير مستعمل؛ التخزين دون اتصال يتم عبر `localStorage` في المتصفح.

## التشغيل

```bash
npm install
cp .env.example .env            # عدّل DATABASE_URL و APP_SECRET ومفاتيح المزودين
npx drizzle-kit push            # إنشاء الجداول
npm run dev                     # تطوير  →  http://localhost:3000
# أو للإنتاج
npm run build && npm start
```

الاختبارات: `npx vitest run` (51 اختباراً). أداة مساعدة: `node scripts/fake-provider.mjs` تشغّل مزودين وهميين (انظر `docs/development/testing.md`).

أول حساب يُسجَّل يصبح **مديراً** تلقائياً (أو البريد في `ADMIN_EMAIL`). من لوحة `/admin/providers` تُدار المزودات والمواد.

## متغيرات البيئة

| المتغير | الوظيفة |
|---|---|
| `DATABASE_URL` | اتصال PostgreSQL |
| `APP_SECRET` | سر تشفير (AES-256-GCM) للمفاتيح المخزنة من لوحة الإدارة. بدونه لا تُحفظ مفاتيح في القاعدة (يبقى خيار متغير البيئة) |
| `OPENAI_API_KEY` / `GEMINI_API_KEY` / `ANTHROPIC_API_KEY` | تُفعّل المزودين الافتراضيين تلقائياً عند أول تشغيل |
| `OLLAMA_BASE_URL` / `OLLAMA_MODEL` | نموذج محلي على خادم المنصة |
| `AI_ROUTING_POLICY` | `quality` (افتراضي) أو `cost` أو `speed` |
| `ADMIN_EMAIL` | بريد يُمنح دور المدير عند التسجيل |

لا تُرسل أي مفاتيح إلى المتصفح أبداً؛ كل استدعاءات المزودين من الخادم فقط.

## النشر

1. وفّر PostgreSQL وضع `DATABASE_URL` و`APP_SECRET` (`openssl rand -hex 32`).
2. `npx drizzle-kit push` ثم `npm run build && npm start` (المنفذ 3000).
3. ضع التطبيق خلف وكيل عكسي يفعّل **HTTPS** (Caddy/Nginx). الكوكي يصبح `Secure` تلقائياً عند `X-Forwarded-Proto: https`، وHTTPS شرط لتثبيت PWA وعمل Service Worker.
4. (اختياري) ثبّت Ollama على الخادم: `ollama pull qwen2.5:3b` ثم تحقق من `/status`.

## الوظائف: ما يعمل وما لم يُنفَّذ

الحالة الدقيقة لكل بند في `docs/development/status.md`. باختصار:

**يعمل ومُختبر:** الواجهة العربية RTL المتجاوبة · اختيار المستوى والمادة (المواد قابلة للإدارة) · إدخال التمرين كتابةً · الأزرار السبعة المستقلة بسياق محفوظ · تكييف الشرح بالمستوى والمادة · AI Provider Manager (OpenAI-compatible, Gemini, Claude, Ollama) · AI Router مع التحويل التلقائي والإيقاف المؤقت والحدود اليومية · لوحة إدارة المزودين (اختبار اتصال، أولوية، تفعيل، حدود، تنبيهات، آخر الأخطاء) · تشفير المفاتيح · الحسابات والأدوار · سجل التمارين والمزامنة وحذف البيانات · PWA وService Worker · تحقق حسابي محلي دون إنترنت · صفحة حالة الخدمات.

**مكتوب لكن لم يُختبر بمفتاح/بيئة حقيقية هنا:** استدعاء OpenAI وGemini وClaude الحقيقيين (اختُبرت المحوّلات ببروتوكولاتها عبر خوادم HTTP وهمية؛ لا مفاتيح حقيقية في بيئة التطوير) · Ollama حقيقي (اختُبر ببروتوكوله فقط) · OCR عبر Tesseract.js في متصفح حقيقي (يحتاج اتصالاً أول مرة لتنزيل ملفات اللغة؛ لم يُختبر آلياً) · الكاميرا على جهاز فعلي.

**لم يُنفَّذ بعد (بصراحة):** تشغيل نموذج داخل المتصفح عبر WebLLM/WebGPU (يوجد **فحص إمكانات فقط**) · استعمال Ollama الموجود على جهاز المستخدم (كشف فقط) · SQLite · تغليف Capacitor/APK (دراسة في `docs/development/capacitor.md`) · اختبارات واجهة آلية (E2E في متصفح) واختبارات أجهزة حقيقية.
